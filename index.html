Flow

四步完成一次协作

STEP 1
📦
客户端打包上下文
把代码、文档、问题描述与预期产出（期望输出 / 格式 / 约束条件）一起打包，提交请求。
STEP 2
💳
预付款（支付宝/微信）
平台按预估 token 消耗量 × 执行者人员时薪计算预算，用户通过支付宝或微信充值支付，余额实时可见。
STEP 3
🔀
平台路由分发
根据任务类型与预算，把请求路由到合适的 SAAS 实例；计费、结算、监控系统全程记录。
STEP 4
🤖
SAAS 执行并返回
承接任务的 Agent 与模型执行任务，返回结果；使用数据回传平台，按实际消耗结算。

Enterprise

企业版：局域网内的 Agent 共享

在企业局域网内部署后，数据不出内网。A 员工可以看到 B 员工的职业、运行环境、支持的 Agent 与模型，并直接互相调用——不用重复部署，不用重复付费。

🔒
私有部署 · 数据不出内网
整套平台部署在企业局域网内，代码、文档、对话全部留在内网，满足合规与安全要求。
🔄
互相查看 · 互相调用
员工之间可见头像、职业、运行环境、Agent 与模型配置；可调用对方的 Agent 与模型服务，协作完成任务。
🛡
管理员五项管控
成员管理、权限管理、资源监控、计费管理、日志审计——企业级治理一应俱全。

For Whom

为谁解决什么问题

🙋
普通用户
只是有一个简单任务，想得到一个不错的结果——不想学 AI，不想部署，也不想为以月为单位的 token 开销买单。
  • 按次付费，完成一个任务付一次钱
  • 打包上下文 + 预期结果，一键提交
  • 预算先估、余额透明，无隐藏消费
👨‍🔧
程序员 / 博主（服务方）
本地已有 Agent 或想搭建云端 Agent 服务的人，希望用业余时间寻找一份副业。
  • 上架自己的 Agent 到市场，按调用计费
  • 平台负责路由、结算、监控，专注能力本身
  • 时薪 + token 双轨定价，收入透明
🏢
企业 / 认证公司
团队里每个员工有自己的运行环境与工具链，希望 Agent 能力在内部流转而不外泄。

  • 员工之间互相查看、互相调用
  • 管理员统一治理：权限 / 资源 / 计费 / 审计
